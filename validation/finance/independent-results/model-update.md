## EPS、估值及资产负债表边界

ASSUMPTIONS 给出新旧模型均使用全年加权平均稀释股数 100，属于固定的明确假设，不能据此声称股数已实际披露。直接用全年归属净利润计算，不加总舍入后的季度 EPS，也不平均未知的季度股数。

- 旧 EPS = 125÷100 = 1.25；新 EPS = 98÷100 = 0.98；变动 = -0.27，降幅 = 21.60%。
- 给定且不变的 P/E 倍数为 20：旧条件估值 = 1.25×20 = 25.00；新条件估值 = 0.98×20 = 19.60；变动 = -5.40，降幅 = 21.60%。变化完全来自盈利修订，倍数及股数不变。该结果是条件情景值，不是承诺的价格。
- 案例 reported_balance_sheet 给出报告现金 180、债务 60：净现金 = 180−60 = 120，等价净债务 = 60−180 = -120。该字段未单独注明资产负债表时点，也未提供旧余额，不能展示现金或负债变动。现金未被额外加入 P/E 估值，以免混用估值方法。

当前股价、市场一致预期 EPS、FY2027 预测、DCF 现金流与折现率、原投资评级均缺失。EV 估值所需的企业价值或对应倍数/盈利基数及完整权益桥接亦不具备。分部明细、资本开支、营运资本、股数变动及非经常性项目明细均未提供；缺失不是零。因此不计算一致预期偏差、涨跌空间、DCF、EV 目标价，不创造评级，也不声称已更新工作簿。
