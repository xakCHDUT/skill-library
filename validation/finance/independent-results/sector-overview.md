## 样本份额及不可计算的指标

可比收入合计只包含 A、B、D：300+250+100=650。C 的 1,000 不加入，650 也不代表市场总额。

- A 的样本份额 = 300÷650 = 46.1538%。
- B 的样本份额 = 250÷650 = 38.4615%。
- D 的样本份额 = 100÷650 = 15.3846%。

上述比例的分母仅是这三个观察对象，必须称为“样本份额”。市场总额缺失，三家市场份额均未知；遗漏供应商及 C 的目标分部规模也未知。因此无法确认全行业龙头或 CR3 等集中度，不能把样本合计直接命名为集中度。没有往年同范围收入，不能计算同比增速或 CAGR。

## 价值链、竞争判断与下一步证据

现有材料仅定位到工业温控器销售这一产品范围。没有供应商、客户分组、渠道、经销转售、纵向交易或产业链阶段明细，无法实证绘制完整价值链或判断各环节议价权。650 是所给同范围公司收入的算术合计；缺乏交易链资料，亦不能将它升级为无重复计算的终端需求估计。技术壁垒、周期暴露、监管影响、并购整合及利润来源均缺少证据，不据此填充结论。
