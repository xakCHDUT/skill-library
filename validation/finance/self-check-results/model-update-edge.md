# 合成案例：Boreal Instruments 的零基数与缺失数据

数据仅来自合成材料 EDGE，截止 2026-08-15，金额单位为人民币百万元，不是实际公司研究。

季度收入从原预测 0 增至报告实际 5，绝对增加 5；原基数为零，收入增长百分比无定义。归母利润由原预测亏损 2 转为实际盈利 1，改善 3，属于扭亏；不以负基数百分比描述改善幅度。

加权平均稀释股数没有提供，因此 EPS 不可计算。目标倍数、现价、市场一致预期和未来季度预测也均缺失，所以目标价、上涨空间、一致预期比较及全年预测都不可计算。缺失值不是 0，也不能从单季度收入与利润推断股数或估值。未创建或修改任何真实模型文件。
