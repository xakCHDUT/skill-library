# 合成任务的处理说明

本目录是技能适配作者按案例材料实际起草的输出，不是独立盲测，也不是来自真实单位的成稿。

1. 电脑购置请示：12×7200=86400元，审批诉求保持单一。经费来源、预算安排和联系人尚缺，保留为待补充稿，不能直接作为信息齐全的正式请示。
2. 安全排查：报告和请示分成两份。报告保留6项、已整改4项、未整改2项及费用未批的事实；另写3万元线路维修请示，避免报告夹带审批请求，也不丢失用户的维修诉求。没有声称维修已获批或已经实施。
3. 科研诚信培训：只写材料确认的主题与对象；保留日期、时间、地点、联系人缺口。未增加报名、签到、处罚或另行通知承诺，当前为待补充稿。

Word 样例使用本机已安装的宋体、黑体、楷体作字体配置；未复制字体。样例用于内容和导出检查，不宣称单位专用模板或严格国标版式。
