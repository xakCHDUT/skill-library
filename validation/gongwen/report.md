## 可复现

Python 3.11+ 即可运行导出与本检查器，不需要下载字体或安装额外 Python 包。从技能库根目录运行：

```text
python -B validation/gongwen/check_export.py --output work/gongwen-check/results.json
python -B skills/official-document-drafting/src/scripts/generate_docx.py validation/gongwen/drafts/request.md -o work/gongwen-check/request.docx --doc-type 请示 --title-font 宋体 --body-font 宋体 --title-wrap off
```

可给检查器添加 `--upstream /固定版本原稿目录` 复现上游覆盖风险，原稿路径必须含 `src/scripts/generate_docx.py`。该步骤只作用于检查器创建的临时合成文件。

本机 Windows 的 bundled runtime 没有 LibreOffice，未调用桌面 LibreOffice。视觉验证实际采用独立隐藏 Word COM 实例（只读打开、关闭不保存）输出 PDF，再由 bundled Poppler 转 PNG；没有把这一路线称为 `render_docx.py` 验证。Word、PDF 和 PNG 仅保留本地交付/工作目录，公共库保留输入、纯文本检查器、结果及哈希。
